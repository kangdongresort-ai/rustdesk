{{COMPANY}} 원격지원

상담원이 고객님의 PC 화면을 보면서 문제를 해결해 드립니다.

실행파일 접속

현재 Windows PC가 아닌 것 같습니다. 원격지원은 Windows PC에서 접속해 주세요.

버튼을 누르면 원격지원 프로그램이 다운로드됩니다. 설치는 필요 없습니다.

이용 방법

  1. [실행파일 접속] 버튼을 눌러 프로그램을 내려받습니다.
  2. 다운로드가 끝나면 파일을 실행합니다.
    "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요.
  3. 프로그램 화면에 표시된 ID와 비밀번호를 상담원에게 알려 주세요.
  4. 상담원이 연결을 요청하면 수락을 누르세요. 원격지원이 시작됩니다.
  5. 지원이 끝나면 프로그램 창을 닫으면 연결이 완전히 종료됩니다.
